## Com o que trabalho

**Dados** — ETL e pipelines agendados, modelagem dimensional, Data Marts, Azure SQL
**Modelagem** — classificação e propensão com scikit-learn, validação em hold-out, calibração, controle de leakage, monitoramento de drift
**Backend** — Python com FastAPI, API REST, webhooks, integração entre sistemas
**Entrega** — Docker, nginx, VPS Linux, CI/CD com GitHub Actions
**BI** — Power BI, Looker Studio, Tableau
