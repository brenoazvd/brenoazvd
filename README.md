## O que eu construí

**Plataforma interna, do dado ao frontend.** ETL em Python de TOTVS e Kommo para
Azure SQL em star schema, API em FastAPI com mais de 30 endpoints organizados por
módulo, frontend em React e TypeScript, deploy em VPS com Docker, nginx e CI/CD por
GitHub Actions.

**Integração e automação do CRM.** ETL do Kommo para Azure SQL 4x ao dia, com merge
incremental e auto-heal. Com a visibilidade que o funil e os dashboards deram ao
comercial, 3 escolas bateram meta de captação, algumas voltando a atingir depois de
anos sem conseguir.

**Risco e retenção escolar.** Índices compostos transparentes e um classificador
calibrado em scikit-learn, com controle de leakage documentado feature a feature e
monitoramento de drift por período. Começou como POC em Streamlit e hoje roda
como módulo da plataforma interna.

**Sincronização TOTVS para Azure SQL.** ETL em Python rodando na VPS, agendado por
cron 4x ao dia, intercalado com o ETL do CRM.
